# Example Deck — Voiceover Script

**Story spine:**
- Hook — this demo shows cue-aware narration end to end.
- Context — a result slide plus a software walkthrough.
- Method — one visual anchor per idea.
- Proof — the chart and the summary card.
- Insight — pointers should be selective, not constant.
- Action — apply the same cue discipline to your own deck.

## Slide 1 — Introduction
**Role:** hook
**[~10s]**
**Say:**
This short example demonstrates cue-aware narration without forcing a pointer on every slide.

## Slide 2 — Results
**Role:** proof
**[~25s]**
**Visuals:**
- [A] left — main chart
- [B] upper-right — key result card

**Say:**
[A] The chart on the left provides the main pattern for this result.

[B] The summary card on the upper right gives the figure to remember.

## Slide 3 — Software walkthrough
**Role:** action
**[~20s]**
**Visuals:**
- [A] top-left — navigation button
- [B] lower-right — confirmation button

**Say:**
[A] Start with the navigation control here.

[B] After reviewing the settings, use the confirmation button in the lower-right area to continue.
